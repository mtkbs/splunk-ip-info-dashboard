# splunk-ip-info-dashboard
Splunk dashboard designed to display and visualize ip traffic coming into a network

The project's directory system is as follows:

```splunk-ip-info-dashboard/
splunk-ip-info-dashboard/
    ├── DNS/
    │   ├── DNSLookup.spl
    │   ├── DNSLookupMap.png
    │   └── DNSLookupMap.spl
    ├── blocked/
    │   ├── blockedIPS.spl
    │   ├── blockedIPSMap.png
    │   └── blockedIPSMap.spl
    ├── firewallTraffic/
    │   ├── inboundTraffic.spl
    │   ├── inboundTrafficMap.png
    │   └── inboundTrafficMap.spl
    ├── scanning/
    │   └── webCrawlerDetector.spl
    ├── README.md
    └── allTraffic.spl
```
